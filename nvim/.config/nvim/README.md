# Шпаргалка по Neovim

`<leader>` — пробел. Сначала найди нужный код, затем внеси изменение, проверь diff и добавь в Git только нужные части.

На стартовом экране нажми `r`, чтобы открыть эту шпаргалку в режиме только для чтения. Тема — Moonfly с прозрачным фоном. Русская раскладка работает в Normal mode через `langmap`; `spelllang` настроен для английского и русского языков (проверка включается командой `:set spell`).

## Поиск и навигация

| Клавиши | Действие |
| --- | --- |
| `<leader>ff` / `<leader>fb` | Найти файл / открытый буфер |
| `<leader>fg` / `<leader>fl` | Поиск текста в проекте / нечёткий поиск в текущем файле через Telescope |
| `<leader>fu` | Найти первое совпадение с начала файла до `#` в строке |
| `/`, `n`, `N` | Поиск в файле и переход между совпадениями |
| `gd`, `gr`, `<C-o>` | Определение, использования символа, возврат назад |
| `<leader>e` | Открыть файловый менеджер Oil |
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | Переход между окнами и панелями tmux, в том числе из Oil |
| `<leader>oh` / `<leader>or` в Oil | Открыть файл в горизонтальном окне / обновить список |
| `<C-p>` в Oil | Включить или выключить предпросмотр; выбор сохраняется до завершения Neovim, при запуске предпросмотр включён |

В Telescope `<C-q>` переносит результаты в quickfix; `]q` / `[q` листают их. `<leader>fu` считает `#` началом комментария в любой строке и не разбирает синтаксис языка.

## Рефакторинг и проверка

`gr` — найти использования, `<leader>rn` — переименовать символ через LSP, `<leader>ca` — доступные действия. `<leader>fd` показывает диагностику, `[d` / `]d` переходят между ошибками. Сохранить файл — `<leader>w`; форматировать вручную — `<leader>cf`.

## Git и Gitsigns

| Клавиши | Действие |
| --- | --- |
| `<leader>fs` | Git status в Telescope |
| `]h` / `[h` | Следующий / предыдущий изменённый блок |
| `<leader>ghp` | Показать изменение в текущем блоке |
| `<leader>ghs` | Добавить блок в Git index; в Visual mode — выделенную часть |
| `<leader>gdo` / `<leader>gdc` | Открыть / закрыть Diffview |
| `<leader>gdh` | История текущего файла |

Обычный порядок: `]h` → `<leader>ghp` → при необходимости `<leader>ghs` → `<leader>gdo` для проверки итогового diff.

## Конфликты при мердже

`<leader>gdo` открывает просмотр конфликта, `<leader>gdl` собирает конфликты в quickfix. В конфликтном файле `]x` / `[x` листают конфликты; `co` / `ct` / `cb` выбирают ours / theirs / both. Перед выбором посмотри обе стороны: при rebase смысл ours и theirs легко перепутать.

При наличии маркера `<<<<<<< ` автоформатирование при сохранении пропускается. `<leader>cF` переключает автоформатирование для текущего буфера, если нужно сохранить уже разрешённый файл без дополнительных изменений.
